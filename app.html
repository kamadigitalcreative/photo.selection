Panduan Penggunaan Lengkap

Ikuti langkah-langkah praktis ini untuk mempermudah alur kerja pemilihan foto bersama klien Anda.

1. Persiapan Link Google Drive

Sebelum membuat project, pastikan Anda sudah mengupload foto mentahan ke Google Drive.

  • Klik kanan pada folder foto di Google Drive, pilih Bagikan (Share).
  • Ubah akses umum menjadi "Siapa saja yang memiliki link" (Anyone with the link).
  • Pastikan perannya adalah Pelihat (Viewer) saja.
  • Salin link folder tersebut.

2. Membuat Project Klien

Masuk ke menu Projects, lalu klik tombol New Project. Isi formulir dengan lengkap:

  • Link G-Drive: Paste link folder yang sudah disiapkan di Langkah 1.
  • Batas Foto: Tentukan jumlah maksimal foto yang boleh dipilih oleh klien.
  • Password: Boleh dikosongkan jika Anda tidak ingin galeri klien dikunci password.

3. Mengirim Galeri ke Klien

Setelah project selesai dibuat, cari nama klien Anda di daftar tabel Project.

Klik tombol Copy berwarna hijau. Sistem akan otomatis menyalin teks rapi (berisi sapaan, link galeri, dan password). Anda tinggal Paste (Tempel) di chat WhatsApp klien Anda.

4. Memantau Progress Klien

Anda tidak perlu terus bertanya ke klien apakah mereka sudah selesai memilih. Cukup buka menu Pantau Klien untuk melihat status secara real-time.

  • New Klien belum membuka galeri sama sekali.
  • Memilih Klien sudah login dan sedang melakukan proses pemilihan.
  • Selesai Klien sudah mengklik tombol konfirmasi selesai. Klien akan mengirimkan rekap file foto ke WA Anda.

5. Sortir File Otomatis (Proses Akhir)

Ini adalah fitur paling ajaib untuk menghemat waktu kerja Anda berjam-jam!

  1. Salin (Copy) seluruh list nama file foto yang dikirimkan klien ke WhatsApp Anda.
  2. Buka menu Projects, lalu klik tombol abu-abu Sortir Lokal.
  3. Sistem akan meminta Anda memilih folder asli (mentahan) di komputer / laptop Anda.
  4. Paste list dari klien ke dalam kotak yang disediakan.
  5. Klik tombol Proses & Download ZIP. Sistem akan bekerja memisahkan foto-foto tersebut lalu mengunduhnya dalam bentuk 1 file ZIP yang rapi!
