Panduan Penggunaan

Pelajari cara menggunakan sistem Photo Selection untuk mempermudah pekerjaan Anda.

1. Membuat Project Baru

Masuk ke menu Projects, klik tombol New Project. Isi nama klien, link Google Drive yang berisi folder foto klien (pastikan akses linknya diset "Siapa saja yang memiliki link / Viewer"), nomor WhatsApp Fotografer, dan batas maksimal foto yang boleh dipilih. Password opsional jika ingin galeri diprivasi.

2. Mengirim Link ke Klien

Setelah project terbuat, klik tombol Copy pada baris project tersebut. Teks otomatis disalin beserta link dan passwordnya. Anda tinggal menempelkannya (Paste) di chat WhatsApp klien Anda.

3. Memantau Proses Pemilihan

Buka menu Pantau Klien. Di sini Anda bisa melihat status secara real-time apakah klien Belum Memilih, Sedang Memilih, atau sudah Selesai. Jika sudah selesai, klien akan mengirimkan list file foto ke WhatsApp Anda.

4. Sortir File Lokal (Otomatis ZIP)

Setelah menerima list foto dari klien di WA, copy teks list tersebut. Masuk ke menu Projects > klik Sortir Lokal. Pilih folder asli (mentahan) di komputer Anda, lalu paste list dari klien ke kotak yang disediakan, lalu klik proses. Sistem otomatis menyortir foto ke dalam file ZIP.
