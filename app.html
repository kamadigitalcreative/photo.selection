PUSAT BANTUAN

Panduan Aplikasi Lengkap

Pelajari alur kerja cerdas untuk mengirim dan menerima foto pilihan klien Anda dalam hitungan menit.

1. Siapkan Link Google Drive

Sebelum membuat project, pastikan Anda sudah mengupload seluruh foto mentahan ke Google Drive.

  • Ubah akses folder Drive menjadi "Siapa saja yang memiliki link" (Anyone with the link).
  • Pastikan perannya disetel sebagai Pelihat (Viewer) saja.
  • Salin (Copy) link folder tersebut.

2. Buat Project Klien

Masuk ke menu Projects, lalu klik tombol New Project. Isi formulir dengan lengkap dan benar.

  • Link G-Drive: Tempel link folder dari Langkah 1.
  • Batas Foto: Tentukan kuota maksimal foto yang boleh dipilih oleh klien.
  • Password: Biarkan kosong jika tidak ingin mengunci galeri klien.

3. Kirim Galeri ke Klien

Setelah project berhasil dibuat, temukan nama klien Anda di daftar tabel Project.

Klik tombol Copy berwarna biru pada kartu project. Sistem akan menyalin teks sapaan otomatis beserta link galeri. Anda tinggal Paste di chat WhatsApp klien.

4. Pantau Progress Klien

Tidak perlu lagi menagih klien terus-menerus. Buka menu Pantau Klien untuk melihat status secara real-time.

New Memilih Selesai

5. Sortir File Otomatis (Proses Akhir)

Fitur ajaib untuk menghemat waktu kerja Anda berjam-jam! Pisahkan ratusan foto hanya dalam satu klik saja.

  • 1
    Salin (Copy) daftar nama file foto dari pesan WhatsApp klien Anda.
  • 2
    Di menu Projects, klik tombol Sortir Lokal (berwarna ungu) di bagian bawah kartu project.
  • 3
    Pilih folder foto master (mentahan) di komputer Anda, lalu paste list dari klien ke kotak yang disediakan.
  • 4
    Klik Proses & Download ZIP. Sistem otomatis memisahkan foto-foto tersebut!
